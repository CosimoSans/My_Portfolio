## Data Analysis & Dashboard

This project focuses on transforming raw and unstructured data into a clear and interactive dashboard using Power BI, following a complete data workflow from data cleaning to visualization.

The starting dataset contained multiple data quality issues, including missing values, inconsistent formats and incorrect date representations. Before building the dashboard, a data cleaning phase was required to ensure accuracy and reliability.

### Project Goals

The main objectives of this project were:

- Clean and prepare raw data for analysis
- Ensure consistency and reliability of key metrics
- Explore the dataset to identify trends and patterns
- Present insights through a clear and interactive dashboard

### Approach

The project was developed in two main phases:

**1. Data Preparation**
- Cleaning missing and blank values
- Fixing inconsistent formats and standardizing fields
- Correcting date formats
- Structuring the dataset for analysis

**2. Data Analysis & Visualization**
- Identifying key metrics and relevant dimensions
- Aggregating data to highlight trends and distributions
- Creating visual elements to support data interpretation
- Designing an intuitive dashboard layout

The dashboard was built to provide a clear overview of the data, allowing users to quickly understand key insights and explore the dataset interactively.

### Insights & Conclusions

The analysis highlights several key aspects of the data analyst profession based on the survey results:

- The profession appears to be balanced in terms of gender distribution, with no significant differences between male and female participation.
- Overall, the role offers a good work-life balance, as reflected by the responses collected.
- Compensation shows mixed levels of satisfaction, with some indications of lower perceived value, particularly in more competitive markets.
- Technical skills such as SQL remain central to the role, even though their perception may vary depending on the context.

These insights demonstrate how survey data can be used to better understand industry trends and perceptions, providing a clearer view of both the strengths and challenges of the data analyst profession.

From an analytical perspective, this project highlights the importance of transforming raw data into structured information in order to extract meaningful and interpretable insights through visualization.
