
**Data Analysis with Excel (Functions & Pivot Tables)**

**Overview**

This project showcases an end-to-end data analysis workflow performed in Excel, starting from raw data and progressing through data preparation, enrichment, and final analysis using pivot tables.

The goal is to transform unstructured data into meaningful insights using Excel functions and analytical tools.

**Dataset**

The file contains:

- A raw dataset with transactional records  
- Reference tables with additional information  
- A working sheet where data is cleaned and enriched  
- Pivot tables used for summarization  
- A final interactive dashboard for visualization  

**Data Preparation**

The raw data was processed and enriched using Excel formulas:

- Lookup functions (INDEX/MATCH or similar) to combine data from multiple tables  
- Conditional logic (IF statements) to standardize and categorize values  
- Data cleaning to handle missing or inconsistent values  
- Formatting adjustments for dates, text, and numeric fields  

The result is a structured dataset ready for analysis.

**Analysis**

Pivot tables were used to:

- Aggregate data across different dimensions  
- Identify patterns and trends  
- Compare values across groups  
- Support exploration of the dataset from multiple perspectives  

**Dashboard**

The final sheet contains an interactive dashboard built on top of pivot tables and charts.

- Provides a clear overview of key metrics  
- Includes filters and slicers for dynamic data exploration  
- Allows quick drill-down into specific segments  
- Improves readability through visual elements and structured layout  

This layer turns the analysis into a user-friendly reporting tool.

**Key Concepts Demonstrated**

- Data preparation and enrichment  
- Use of Excel formulas  
- Dataset integration  
- Aggregation with pivot tables  
- Interactive dashboard design  

**How to Use**

1. Review the raw dataset  
2. Explore the transformation steps in the working sheet  
3. Analyze the pivot tables  
4. Use the dashboard to explore insights  

**Purpose**

This project demonstrates practical skills in data analysis, data quality, and reporting using Excel.
